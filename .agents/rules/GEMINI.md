# GEMINI.md — Universal Workspace Rule Entrypoint

All core architectural, coding, and governance rules for the active workspace are loaded from `.agents/rules/`:
- `agents.md` (Core Constitution: Zero-Waste Protocol, Karpathy Simplicity First, Change Policy & Subagent Oversight) — Always follow.
- `backend.md` (Backend Clean Code, Idioms & Static Analysis Standards) — Apply when working on Backend source files.
- `frontend.md` (Frontend Component, State & Zero-Waste Standards) — Apply when working on Frontend UI files.
- `testing-mandatory.md` (On-Demand & Scoped Verification Rules) — Apply for all build, test, and verification tasks.
- `debug.md` (Systematic Sherlock & Surgeon QA Protocol) — Apply when troubleshooting or fixing bugs.
- `planning-architect.md` (Simplicity-First Strategy & Atomic WBS Design) — Apply when designing architecture or planning features.

> **Gợi ý Chuyên biệt hóa (Stack Customization)**: Khi bắt đầu dự án với ngôn ngữ/framework cụ thể (như Rust, .NET, Go, Python, Java, Node.js...), hãy gọi skill `/customize-stack` để tự động cập nhật phần cấu hình đặc thù ngôn ngữ vào bộ Rules và Skills này.
